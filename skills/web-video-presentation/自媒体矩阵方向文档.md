# 自媒体矩阵方向文档

## 项目介绍

这个项目是一个把文章、口播稿、科普内容或产品说明，做成点击驱动的 16:9 网页演示的工具。它不是传统 PPT，而是一个用 Web 技术实现的“视频化页面”：

- 每次点击推进一个步骤
- 每一步独占一屏
- 适合录屏成视频
- 可以接 AI 配音
- 可以用生图、动画、图表、代码、交互来表达内容

它更像“为录屏设计的网页舞台”，而不是办公软件里的幻灯片。

## 项目特点

### 1. 16:9 网页舞台

内容写在固定比例的网页画布里，适合横屏录制和视频发布。

### 2. 一步一屏

每个 step 对应一个节拍，画面不会堆太多信息，适合讲清楚一个点。

### 3. 支持自动播放和配音

可以手动推进，也可以进入自动播放模式；如果接了音频，能配合节奏自动切换。

### 4. 适合动画表达

比普通 PPT 更适合做渐进揭示、对比、流程、时间线、关系图、数据变化等内容。

### 5. 主题化能力强

可以切换不同视觉主题，适配科技、商业、历史、科普、生活方式等内容风格。

### 6. 便于做视频内容

最终目标不是导出幻灯片文件，而是录屏产出视频，因此特别适合自媒体发布。

## 定位

这个项目适合做“视频化网页演示”内容生产工具。核心不是传统 PPT，而是用 Web 动画、分章节奏和 AI 配音，稳定产出适合录屏的视频内容。

## 建议的 4 个方向

### 1. AI / 技术工具号

适合内容：

- AI 工具评测
- Agent 工作流
- 编程工具拆解
- 软件功能对比
- 效率提升方法

适合平台：

- B 站：完整讲解
- 抖音：短结论切片
- 视频号：实用技巧
- 小红书：清单型内容

### 2. 商业案例 / 公司拆解号

适合内容：

- 一家公司怎么赚钱
- 一个产品为什么爆
- 一个行业的利润链路
- 品牌增长或翻车复盘
- 商业模式拆解

适合平台：

- B 站：深度分析
- 视频号：成熟用户向
- 小红书：结构化图解
- 抖音：反差型开头

### 3. 历史故事 / 人物命运号

适合内容：

- 历史人物的关键选择
- 改革成败原因
- 朝代兴衰逻辑
- 战争 / 迁徙 / 贸易的因果链
- 关键事件复盘

适合平台：

- B 站：完整叙事
- 视频号：中长视频
- 抖音：强钩子故事
- 小红书：人物卡片 + 时间线

### 4. 生活科学 / 世界机制号

适合内容：

- 为什么日常现象会发生
- 消费、睡眠、运动、心理机制
- 城市运行逻辑
- 产品设计原理
- 生活中的科学解释

适合平台：

- 小红书：收藏型内容
- 抖音：易传播问题型内容
- 视频号：通俗解释
- B 站：系列化科普

## 平台分发建议

### B 站

适合长一点、讲完整逻辑的内容，重点是解释清楚。

### 抖音

适合强钩子、强结论、节奏快的短内容，前三秒最重要。

### 微信视频号

适合商业、历史、社会经验类内容，面向更成熟的用户。

### 小红书

适合图解、清单、收藏型内容，尤其适合工具、生活科学、认知类选题。

## 推荐的矩阵结构

建议先做 4 个账号：

1. AI / 技术工具
2. 商业案例拆解
3. 历史故事演绎
4. 生活科学解释

这样分工清晰，也方便复用同一套网页演示能力。

## 内容模板

推荐统一成这种结构：

1. 先抛问题或反常识结论
2. 解释现象是什么
3. 拆背后的机制
4. 给出对比或案例
5. 最后总结和行动建议

## 适合这个项目的优势

- 可以一页一页推进，节奏天然适合口播
- 可以把复杂概念做成动画解释
- 可以接 AI 配音，降低出片成本
- 可以用生图补足历史、商业、场景类画面
- 同一套内容可以裁成长视频和短视频

## 结论

如果要做矩阵号，这个项目最适合做“解释型内容”的工业化生产工具。  
最优先的方向是：AI / 技术工具、商业案例、历史故事、生活科学。
